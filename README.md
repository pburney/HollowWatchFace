# Hollow Watch Face

A graveyard-at-night Wear OS watch face: the time sits carved into four
crenellated stone tombstones, ghosts drift out from among the stones and
change every minute, a moon-phase icon and a weather complication sit up
top, and the whole thing is scattered with stars. Built from
[Paul's own paper sketch](https://github.com/pburney/HollowWatchFace) —
not a numeral-base variant like [RadixWatchFace](https://github.com/pburney/RadixWatchFace),
a standalone themed face of its own.

Built entirely from one Python spec — no app code at all. The whole thing
is [Wear OS Watch Face Format](https://developer.android.com/training/wearables/wff)
(WFF): a declarative XML format Android's watch face renderer executes
directly.

## What's on the face

- **Four stone pillars** show HH:MM — plain carved-ink numerals on a
  crenellated (castle-merlon) silhouette, not a custom digit font; the
  stone shape carries the theme, the ink carries the digit.
- **Ghosts** — six hand-drawn poses, one keyed to `[MINUTE] % 6`, each
  floating up out of a specific stone. Changes every minute; no two
  adjacent minutes repeat.
- **Moon phase** (top-left) reads WFF's native `[MOON_PHASE_TYPE]` data
  source directly — no complication, no setup, it just works.
- **Weather** (top-right) is a real Wear OS complication — assign a
  provider (e.g. your phone's weather app) in the watch face editor, same
  as any other complication. Unlike moon phase, WFF has no built-in weather
  data source (confirmed against the schema, not assumed), so this is the
  only correct way to show it.
- **Date** (bottom) — the same `DAY_AND_DATE` system-provider complication
  every sibling in this family uses.
- A scattered **star field** over a deep night-blue sky.

## How it works

One Python spec → two outputs, same architecture as
[RadixWatchFace](https://github.com/pburney/RadixWatchFace) and its
siblings:

- `app/src/main/res/raw/watchface.xml` — the real Wear OS Watch Face
  Format file, generated by `tools/gen_watchface.py`.
- `preview.html` — a live browser preview (canvas, vanilla JS, no build
  step) for fast iteration without installing to a watch.

```bash
python3 tools/gen_watchface.py
```
regenerates both, plus the rasterized ghost/moon-phase PNG icons and the
gallery preview thumbnail (all via Pillow — WFF's `<Image>` loader only
handles raster drawables, not VectorDrawable XML).

See `SETUP.md` for building, installing on a watch, and offline XSD
validation.
